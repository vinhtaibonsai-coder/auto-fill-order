## Workflow

```text
Audit current UI
        ↓
Complete UI_INVENTORY
        ↓
Complete FEATURE_MATRIX
        ↓
Freeze IA
        ↓
Freeze routes/navigation
        ↓
Define design system
        ↓
Redesign one page at a time
        ↓
QA
```

## Không được làm

Không bắt AI:

```text
"Redesign toàn bộ dashboard cho đẹp"
```

Thay vào đó:

```text
"Read all UI/UX documents.
Audit current page.
Implement TASK-XXX only.
Do not modify unrelated files."
```
